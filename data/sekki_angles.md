# 二十四節気シリーズ — アングル(観点)ローテーション

同じ節気を毎年出しても内容が被らないように、**切り口の型を3つ**用意する。
その節気の既出年の記事(`articles/sekki_<slug>_*_note.md`)を見て、**まだ使っていない型**を選ぶ。
時事(ニュース・統計・政治・流行)は入れない。差別化はこの型の切り替えと、下記「軽い時候性」で行う。

## 3つの型(全節気に共通で適用できるレンズ)
- **型A — 暦と実感/由来 → 働き方・仕事の区切り**
  暦と体感のズレ・語源・成り立ちを軸に、季節の先取りや区切りとして「仕事の進め方」に応用する。
- **型B — 季語・行事・手紙の文化 → 内面・暮らし**
  その節気の季語や行事(例:残暑見舞い、彼岸、七十二候)を軸に、暮らしと自分の内側へ静かに寄せる。
- **型C — 五感で兆しを拾う → 観察と気づき**
  風・光・音・気温・匂いといった具体の感覚から、季節の移ろいに気づくことそのものを主題にする。

型の選び方: 既出年で使った型を除き、`A → B → C` の順で未使用の型を採る。3年で一巡したら、また A に戻す(ただし前回とは季語・具体を変える)。

## 軽い時候性(入れてよい/入れない)
- **入れてよい(検証できる・古びにくい)**: その年の曜日や連休の並び、お盆・彼岸・祝日との重なり、月の満ち欠け、閏の有無。あくまで暦由来の事実に留める。
- **入れない**: ニュース、事件、政治、経済指標、流行語、数値統計、商用製品名。断定できない時事は書かない。

## 記録の作法
- 記事の冒頭に貼り付け対象外のメモを1行入れる:
  `<!-- 節気:<名> / 年:<YYYY> / アングル:<A|B|C>(要約) ※貼り付け対象外 -->`
- これにより翌年以降の自動生成が既出の型を判別できる。

## 立秋(risshu)の3型・具体例
- **型A(2026・実施済み)**: 「暦は秋、体はまだ夏」という暦と体感のズレ → 季節を先取りする構え・仕事の区切り。
- **型B**: 立秋を境に「暑中見舞い」が「残暑見舞い」に変わる言葉の作法 → 便りと気づかい、暮らしの手ざわり。
- **型C**: 夕風・ひぐらし・高くなる空など、残暑のなかの小さな兆しを五感で拾う → 観察と、移ろいに気づく心。
